# Shifa Ahammed — UI/UX Portfolio

React + Vite + Tailwind CSS + GSAP + Lenis.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

GitHub Pages is deployed through the GitHub Actions workflow in `.github/workflows/deploy.yml`.

Project visuals are placeholders. Update content and contact information before sharing professionally.

Deployment note: npm cache disabled in workflow to support first build without a lockfile.
